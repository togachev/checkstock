# CheckStock — Где сейчас товар?

Прототип системы учёта остатков на складах фулфилмента (ФФ) с поддержкой FBS и FBO.
Выполнен в рамках тестового задания.

**Стек:** Python, FastAPI, PostgreSQL, SQLAlchemy, Jinja2 (Bootstrap 5).
**Запуск:** Docker Compose.

---

## Инструкция по запуску

Требуется установленный Docker и Docker Compose.
В корневой папке проекта выполните:

```bash
docker-compose up --build
```
